### 🌟 Featured Project: Agora (🏠 Marketplace Platform)

> **Agora** connects customers with vetted professional cleaning service providers with live job tracking, dynamic pricing, and automated payment escrow.

* **Monorepo Architecture**:
  * `app/` — Flutter cross-platform mobile client (iOS, Android, Web)
  * `search-web/` — Next.js 15 Search Portal & instant pricing estimator
  * `marketing-site/` — Next.js landing site, SEO hub & onboarding funnel
  * `api/` — NestJS GraphQL API gateway & business logic
  * `terraform/` — GCP Cloud Run, GKE, DNS, and CDN Infrastructure-as-Code
* **Graph Data Architecture**: Powered by **Neo4j**, modeling complex user permissions, service areas, multi-tier pricing, and relational review topologies.
* **Fintech & Escrow**: End-to-end **Stripe Connect** custom onboarding, payment intents, and automated platform fee splits.
* **Geospatial Intelligence**: **Google Maps Platform** Distance Matrix and Places APIs for travel-time routing and live ETA tracking.
* **Cloud & DevOps**: Automated GCP deployments via Terraform, Skaffold, and GitHub Actions.
